# ZENTIX Cursos - Plataforma de Formação Profissional (Versão 1.0)

Este repositório contém o código completo da versão 1.0 da plataforma **ZENTIX Cursos**, desenvolvida para gestão de treinamentos, cursos livres, Normas Regulamentadoras (SST) e validação de certificados.

## 🚀 Estrutura do Projeto

```
/
├── index.html                  # Dashboard principal da Área do Aluno
├── login.html                  # Interface de Login ZENTIX
├── curso.html                  # Sala de Aula Virtual com Player & Anotações
├── cronograma.html             # Cronograma de estudos e progresso
├── certificados.html           # Central de Emissão de Certificados do Aluno
├── valida.html                 # Sistema Público de Validação de Certificado por QR Code
├── admin.html                  # Painel Administrativo de Controle
├── 1-catalogo-completo.html    # Catálogo Completo de Formações
├── 2-normas-reguladoras.html   # Cursos específicos de Segurança do Trabalho (NRs)
├── style.css                   # Sistema de Design Dark Theme com CSS Variables
├── courses-data.js             # Base de Dados em JS dos Cursos & Módulos
├── app.js                      # Interatividade, Filtros e LocalStorage
└── README.md                   # Documentação do Projeto
```

## 🛠️ Tecnologias Utilizadas
- **HTML5 Semantic**: Marcação moderna e acessível.
- **CSS3 Moderno**: Tema escuro (`#0f172a`, `#0066ff`, `#00f0ff`), Flexbox e CSS Grid Responsivo.
- **JavaScript (ES6+)**: Lógica dinâmica sem dependências externas pesadas.
- **LocalStorage API**: Persistência de anotações do aluno e respostas do quiz.
- **FontAwesome 6**: Ícones vetoriais em alta resolução.

## 💻 Como Executar
1. Extraia o conteúdo de `v1.zip`.
2. Abra o arquivo `index.html` ou `login.html` diretamente em qualquer navegador moderno.
3. Para dados de teste no login, clique em **Preencher dados de teste** (E-mail: `aluno@zentix.com` / Senha: `123456`).
